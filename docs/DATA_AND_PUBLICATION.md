# Data and publication

Both research repositories were private when inspected; that visibility is preserved. No participant recordings or metadata tables were added to GitHub. All seven original images are in `docs/figures/`, copied without editing their pixels. The full supplied brief remains local. The original README's externally hosted attachment was replaced by documented local figure assets; its contents and release provenance were not relied on.

Keep authorized data and generated products outside the checkout. `.gitignore` covers common recording formats, pickles, NumPy arrays, motion files, spreadsheets, videos, local settings, and result directories. These rules do not remove previously tracked data or protect history automatically. Pickles must come from trusted local sources.

No new software/figure license, repository visibility change, history rewrite, or public data release was performed. Any later public release requires review of full history, contributor rights, figure metadata, and human-subject release permissions. Private portfolio permission does not by itself authorize public redistribution.
